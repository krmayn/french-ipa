# French IPA privacy policy

Updated November 3, 2026.

French IPA processes text on the current page inside your browser to display French pronunciations and optional English translations. Page text is not sent to the developer or any third party. The IPA dictionary is included with the extension and works offline. English translation uses Chrome’s built-in Translator API on your device. Chrome may download a language pack from Google before first use; the extension does not send the text being translated to Google.

The extension does not collect, transmit, sell or share personal data, browsing history or page content. It has no analytics, advertising, account system or remote code.

The saved settings are your IPA position and English translation mode. They are stored locally using Chrome's extension storage. Source text and translations are held transiently while processing and are not stored in extension storage. Removing the extension removes its saved settings.

The activeTab permission allows the extension to annotate the page after you invoke it. The scripting permission inserts and removes the local annotation code and styles. The storage permission saves your layout and translation-mode preferences. The sidePanel permission opens persistent translation controls alongside the page. The extension does not request permanent access to all websites.

Questions or issues can be reported at https://github.com/krmayn/french-ipa/issues. Information posted to a public GitHub issue is public and is handled by GitHub under its own privacy policy. Do not post private page content there.
