# French IPA privacy policy

Updated November 3, 2026.

French IPA processes text on the current page inside your browser to display French pronunciations. Page text is not sent to the developer or any third party. The dictionary is included with the extension and works offline.

The extension does not collect, transmit, sell or share personal data, browsing history or page content. It has no analytics, advertising, account system or remote code.

The only saved setting is your choice to put IPA above or below the words. This is stored locally using Chrome's extension storage. Removing the extension removes its saved settings.

The activeTab permission allows the extension to annotate the page after you invoke it. The scripting permission inserts and removes the local annotation code and styles. The storage permission saves your layout preference. The extension does not request permanent access to all websites.

Questions or issues can be reported at https://github.com/krmayn/french-ipa/issues. Information posted to a public GitHub issue is public and is handled by GitHub under its own privacy policy. Do not post private page content there.
